# drizzle-sqlite-fts

SQLite FTS5 full-text search for [Drizzle ORM](https://orm.drizzle.team). Declare a search index next to the table it searches, get the virtual table, the sync triggers and the backfill as Drizzle migrations, and query it with typed, injection-safe helpers.

Works with better-sqlite3, libsql/Turso, Cloudflare D1, bun:sqlite and node:sqlite, on drizzle-orm 0.36, 0.45 and 1.0.

> Work in progress: the API is being built in small steps and is not published to npm yet.
